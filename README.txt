SHAZNATION SPA — FILE GUIDE
============================

FILES
- index.html        -> all HTML structure/content (9 sections + navbar + footer)
- css/style.css      -> all styling, scoped per section (edit one section without touching others)
- js/three-bg.js     -> the 3D wireframe background (signature visual, isolated)
- js/main.js         -> mobile menu, scrollspy, FAQ accordion, scroll-reveal

SECTIONS (in order)

2. #about      - About Shaznation
3. #divisions  - 4 division cards (unchanged card design)

5. #process    - Learn / Play / Trade / Connect flow
6. #features   - Upcoming platform features (6 cards)
7. #community  - Built for everyone (4 audience cards)
8. #faq        - Accordion FAQ

EDITING TIP
Every section has its own CSS class prefix (e.g. .why-*, .process-*, .faq-*)
so you can change one section's spacing/colors in style.css without
affecting the others. Section IDs match the navbar links exactly.
